
# Salon Queue Management System

**Live demo:** Deployment pending

## About
A responsive salon queue management application that allows customers to browse services, join a queue, receive a token, and track their service status.

Salon staff can manage the customer queue, while administrators can manage salon services.

## Features
- Browse salon services
- Join the queue and receive a token
- Track queue position and service status
- Staff queue management dashboard
- Live queue display
- Admin service management
- Realtime queue updates

## Technology Stack
- React
- Vite
- TypeScript
- Tailwind CSS
- Node.js
- Express
- SQLite
- Socket.IO
